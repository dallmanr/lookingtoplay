# Looking to play #
A Spring Boot application where I am cementing learning from a course I completed on Udemy for the framework. I am also as it stands, working on a separate Udemy course for testing with JUnit and Mockito and will attempt to apply some TDD to this application.

The idea is for users to be able to find other players to play a game of their choice with.

It uses the Igdb API to find game details, where they can be created and stored within this app if they are not already added.

Users can setup a lobby with x number of players and provide a means for all users to join, for example, a link to a Discord server, Teamspeaker, server IP or name.

Users will be able to leave review of other players they have played with so they can determine if they want to join the lobby.
